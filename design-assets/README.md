## Color Summary

- **Primary:** Fresh Green `#2E8B57` - CTAs, brand accents
- **Secondary:** Soft Teal `#3CB8A8` - Hover states, secondary elements
- **Background:** Warm Cream `#FDF6E3` - Page background
- **Deal/Sale:** Coral `#FF7675` - Sale badges, deals
- **Trust:** Sky Blue `#74B9FF` - Trust badges
- **Text:** Charcoal `#2D3436` - Primary text

## Brand Personality

Warm, friendly, Irish-owned, pet-loving
Avoiding Amazon orange, fresh palette with greens and warm neutrals
